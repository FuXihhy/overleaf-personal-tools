## PDF.js components and fonts

PDF.js includes a JavaScript Brotli decoder and generated integration code for its optional decoders. Their notices are retained even though this extension disables WebAssembly and does not ship PDF.js's decoder WASM binaries or fallback decoder files.

The Liberation license supplied with this PDF.js package is not Apache-2.0. No font license is replaced by the project's license. The original PDF.js package and its upstream repository identify the shipped font distribution; this notice does not claim a separate font licensing review or expand any grant.

## Distribution

The extension ZIP includes this file, the project `LICENSE`, the `licenses/` directory, esbuild's linked legal notices, and the original PDF standard-font license files. The source ZIP includes this file and `licenses/` as well. Build and packaging checks fail if required notices are absent.
