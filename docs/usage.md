# 使用说明

安装后刷新 Overleaf，在 **Settings → Extension** 展开 **LaTeX Preview** 或 **Codex Assistant**。设置跟随网站语言与主题，修改后按当前账号和项目自动保存。**Set as default / 设为默认**用于尚无独立设置的新项目，不改写已有项目的选项或聊天。

## 命令补全与项目宏

扩展分析主文件及其 `\input`、`\include`、项目内 `\usepackage`／`\RequirePackage` 依赖。默认沿用 Overleaf 主文件设置；无法明确判断时才需要手动选择。自动额外宏文件模式查找唯一的 `macros.sty`，也可以手动搜索和选择其他宏文件。“不加载额外文件”不移除主文件已经声明的依赖。

保持 Overleaf 的原生 **Auto-complete** 开启。扩展的命令加入原有列表，并标注宏包或文件来源；只有选择条目后才插入，正常 Undo 可以撤销。补全目录支持常见 `physics`、`amsmath`、`amssymb`、`mathtools`、`braket`、`cancel`、`bm` 命令，以及可解析的项目宏。

主文件和依赖最初从同源项目 ZIP 读取，路径明确时以活动编辑器实时内容覆盖对应文件。重命名、删除或其他窗口／协作者修改了未打开文件后，可在 **LaTeX Preview → 项目支持情况**旁点击 **Reload commands and packages / 重新读取命令与宏包**。这更新补全与预览分析；助手的完整项目缓存另有 **Sync project cache** 操作。

## 三种公式预览

| 选择 | 显示与用途 | 限制 |
| --- | --- | --- |
| MathJax | 浏览器内即时显示，适合输入时查看数学结构 | 支持已适配命令与可解析宏，不执行任意 TeX |
| TeX → Overleaf | 用原项目编译环境在专用云端项目编译 | 需要账号编译资源；同步公式相关文本，不能完整复现原正文状态 |
| TeX → Local / 本机 | 用本机 pdfLaTeX、XeLaTeX 或 LuaLaTeX 隔离编译 | 需对应 helper、系统 TeX Live 及可用沙盒 |

Code 模式将光标移入公式即可预览；LaTeX Visual 模式点入公式并编辑源码时使用同一预览。离开公式后的正文仍沿用 Visual 的原生交互。扩展管理自己的浮窗；启用增强预览时隐藏原生公式浮窗，关闭后恢复网站行为。

TeX 模式先显示 MathJax 即时草稿，输入停顿后再用编译结果替换。草稿不是 TeX 成功结果，宏包、字体及复杂语法可能不同。移动光标或切换公式后，过时结果不会覆盖新的公式。语法不完整时尽量只标红出错部分；不能安全恢复时显示原始源码，不猜测数学含义。

**Preview sources / 预览来源**可以查看、启用和排序宏包及定义文件，后加载的来源优先。选择只影响预览；补全仍可显示已读取的命令。MathJax 能模拟的宏与字体有限，例如 `bm` 使用其粗体实现；需要真实字形时使用 TeX。真实 TeX 也遵循 `\newcommand` 的重复定义规则，不会为避免报错而悄悄改写含义。

### 云端预览工作区

首次启用时，扩展创建或关联专用 **Overleaf Personal Tools — Preview** 项目。同一 Chrome 用户配置、同一 Overleaf 账号的项目复用它；不同设备不会自动共享此绑定。每次同步主文件导言区、当前公式及所需 `.sty`、`.cls`、`.tex` 文本依赖，不复制整篇论文正文。切换项目会清理扩展登记的过时文件，检测到不属于扩展的内容时停止处理。

请不要在此工作区手动写论文或存放其他文件。它会使用 Overleaf 编译资源，并保留预览源文件；删除文件不保证从 Overleaf 历史移除。云端任务有队列、编译间隔和错误退避，网络慢时 TeX 结果会晚于即时草稿。创建结果不明确时先检查已有工作区，避免反复新建。更多机制见[共享云端预览](shared-cloud-preview.md)。

### 本机预览与连接恢复

本机 helper 只把预览所需文本写入独立临时目录，在 macOS sandbox-exec 或 Windows AppContainer 中运行；不启动 localhost HTTP 服务。任务结束清理临时文件，取消会结束该任务的子进程。缺少隔离能力时明确失败，不回退到无沙盒进程。

TeX 预览生成一个只含当前公式的新入口，保留可识别导言区并裁切成单页。正文定义、标签、计数器、交叉引用、外部工具、特殊构建流程以及项目图片／字体二进制仍可能无法复现。切换 TeX 不会自动生成所有宏包的补全目录。

光标在公式内却没有浮窗时，可在 **LaTeX Preview** 的支持区域点 **Reconnect editor / 重新连接编辑器**，它只重新接入当前编辑器，不改文稿、光标或撤销历史。扩展更新导致旧页面上下文失效时仍须刷新页面。后端编译错误则应查看相应后端状态，重连编辑器不会补装宏包或修复 TeX 环境。

## Codex Assistant

助手按 **Overleaf 账号、项目、模型来源**保存独立对话。默认使用本机 Codex；自备 API 在 **Manage API connections** 中管理，然后在项目设置选择来源和模型。设置中的“本机后台已检查”表示登录、模型目录等检查完成，不保证当前项目已同步、模型已回答或桌面可接管该聊天。

选择 Code／LaTeX Visual 文稿后进入助手，输入框上方显示文件、行号及原文引用；转移到输入框时仍保留，主动取消文稿选区或点击移除可撤销引用。**Go to source / 回到引用位置**会核对原文并定位，遇到已改动或不唯一的文字会提示。PDF 选区和不能准确映射到 TeX 的 Visual 小部件选区不在当前支持范围内。

回答逐步显示，支持数学渲染。上滚阅读前文会保留位置，使用“回到最新回复”恢复跟随。选中一条回答中的文字后用 **Quote selected text / 引用所选内容**附到下一问题；可与文稿引用同时使用，不会自动发送。引用中的公式保留 LaTeX，落在公式中的选区端点按完整公式处理。

**Copy source / 复制原文**复制回答的原始 Markdown。普通文字选区跨过公式时，Cmd/Ctrl+C 保留公式源码。默认关闭的 **Click formulas to copy LaTeX**允许单击公式复制不含定界符的 TeX；独立的复制提示开关只控制反馈，不改变复制结果。

### 上下文与缓存

| 模式 | 提供给助手的内容 | 本机源码保留 |
| --- | --- | --- |
| Normal context / 普通上下文 | 选区、附近正文及显式附带引用 | 不为该问题捕获完整项目 |
| On-demand cache / 按需缓存（默认） | 需要时同步完整文本项目，模型通过只读工具查找和读取 | 新临时快照在最后项目页面离开、宽限期结束且无受保护任务时回收 |
| Keep project locally / 在本机保留项目 | 完整文本项目及同样的只读工具 | 保留版本，另存按原路径组织的只读镜像 |

完整项目同步会校验文件字节数和 SHA-256。限制为 2,000 个文本文件、单文件 2 MiB、合计 16 MiB；图片和 PDF 不在文本读取范围内。不完整、超限或无法验证的上下文会阻止发送，并保留草稿。

**Sync project cache**用于手动同步当前源码；**Inspect local versions**显示版本、空间和待清理状态。修改模式不会删除既有保留版本、旧版快照或聊天。临时版本的清理还依赖 Chrome 后续运行和 helper 可达，关闭浏览器不表示源码已经立即消失。排队、处理中或提交结果不明的请求会保护其版本，避免模型读取时被删。

保留镜像是只读辅助副本，不向 Overleaf 回写。不要在镜像里编辑稿件。无法忠实表示的文件名冲突会被拒绝；修改过的镜像不会被静默覆盖。**Clear retained source**会先检查当前版本与占用状态；确认清理后只移除该账号／项目的源码及未完成上传，不删除聊天和 Overleaf 原稿。之后重新同步得到的是新版本，不能假装恢复了已变更的旧稿。

API 完整项目读取要求模型支持 function calling。设置中的 **API reading budget**控制读取轮数、调用次数和总时限；提高上限可能增加等待和 API 费用，不代表每次都会用满。未读完时应检查回答注明的已读范围。

### 排队、引导与停止

回复生成时，默认将追加问题排队；Shift+Enter 换行。可在设置选择排队或支持条件下的 **Steer now / 立即引导**。排队项保存加入时的问题、引用、源码版本和设置，之后改稿不会悄悄改变已排问题。队列最多 8 项，总大小最多 1 MiB，绑定当前账号、项目、来源与聊天；切换这些上下文前需处理或移除队列。

刷新、停止或连接失败后，队列恢复为暂停，只有 **Resume queue / 继续队列**才继续发送。可能已经提交但结果不明的条目要求先检查，不自动重发。可以移除未发项，或在输入框无草稿时取回编辑；重新提交时重新捕获上下文。

引导将新要求交给正在生成的同一 Codex 轮次，仅在后端确认支持时启用。API 使用排队；不通过“停止再重发”模拟引导。Stop 保留已接收到的部分回答；它关闭本地请求，但远端服务可能已经处理或计费。

### 历史与桌面续聊

标题栏的时钟打开 **Conversation history / 对话历史**。新建聊天保留旧会话，历史按页读取。Codex 来源可用 **Open in Codex / 在 Codex 中打开**继续同一已登记聊天；网页会检查桌面新增内容，保留草稿和阅读位置。API 聊天使用独立本机历史，不进入 Codex 桌面。

桌面续聊读取的是此前已同步的项目版本，网页后续编辑需再次同步。首次注册或更新 reader 后应重启 Codex。最终历史出现、实时流式回流、生成中状态和桌面侧栏归类是不同结果；其中一项成功不证明其他项都完成。桌面内部接口不兼容或会话归属不明确时会提示，不自动抢占、复制聊天或重发。

程序安装与数据位置见[安装指南](installation.md)和[数据说明](privacy.md)。
